# Aura 11:11 homepage concepts

## Current implementation direction

On 19 November 2026, the owner chose [03 · Gift Bar](03-gift-bar-concept.png) for the shared typography and shopping UI and [05 · One of One](05-one-of-one-concept.png) for oversized display type and compact personalization controls. Use one design system across the storefront and its interior pages. See the [implementation plan](../../docs/IMPLEMENTATION_PLAN.md) for component and admin requirements.

## 01 · Iris — earlier approved concept

[Original Iris desktop homepage](01-iris-approved.png), approved on 18 November 2026 and retained as design history.

- Porcelain and mineral lilac surfaces, deep ink typography, and electric iris actions.
- Modular gift case hero with closed, open, and exploded views and a drag-to-rotate control.
- Compact gift finder and pincode entry, three shopping categories, a live engraving preview, an atelier strip, and a deep ink footer.

The image is a static design reference. Product imagery and interactions shown in it are illustrative.

## 02 · Pop-up Card — retained alternate

It centers on a dimensional pop-up photo card with a fold/unfold control and carries the printed stationery style through the gift picker, message preview, and footer.

## 05 · One of One — display type and UI reference

A monogrammed 3D canvas tote anchors the hero, with controls for initials, thread color, and rotation. The static mockup includes the gift finder, collection, embroidery feature, packaging section, and footer.
