# Aura 11:11 Gifting Studio

A Vite + React + TypeScript storefront for personalized gifting.

## Tech Stack

- Vite
- React 18
- TypeScript
- Tailwind CSS
- shadcn-ui
- Vitest

## Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Install and Run

```sh
npm install
npm run dev
```

The app runs locally with Vite at the URL shown in your terminal.

## Scripts

- `npm run dev` - start development server
- `npm run build` - create production build
- `npm run preview` - preview production build locally
- `npm run lint` - run ESLint
- `npm run test` - run tests once
- `npm run test:watch` - run tests in watch mode

## Project Structure

- `src/pages` - route-level pages
- `src/components` - reusable UI and feature components
- `src/context` - cart and wishlist state providers/hooks
- `src/data` - static product/category data

## Deployment

Deploy the generated `dist/` output from:

```sh
npm run build
```
